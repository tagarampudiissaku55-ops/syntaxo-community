# SYNTAXO Community Website

React + Vite + Tailwind CSS v4 + Lucide + Framer Motion.

## Run
    npm install
    npm run dev       # development
    npm run build     # production build -> dist/
    npm run preview   # serve the production build

## Replace placeholders (src/config.js)
- `LINKS.join`         - community join link (WhatsApp / Discord / Google Form)
- `LINKS.instagram`    - Instagram profile URL
- `LINKS.contactEmail` - contact email (mailto:)
- `<link rel="canonical">` and `og:` URLs in index.html - set once the domain is chosen
